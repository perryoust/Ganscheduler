# GanScheduler Agents Configuration

## Agent: Scheduler-Core
**Type**: Code Assistant  
**Scope**: Core scheduling logic  
**Skills**: invoices.js, core.js, data.js

```
Models:
  - claude-opus-4-7 (primary)
  - claude-sonnet-4-6 (fast mode)

Permissions:
  - Read/Write: *.js files
  - Execute: npm, node scripts
  - Firebase: PATCH/GET operations
```

## Agent: Firebase-Sync
**Type**: Integration Agent  
**Scope**: Firebase synchronization  
**Tools**: firebase.js, import_export.js

```
Capabilities:
  - Sync invoices to Firebase
  - Idempotent PATCH operations
  - Local backup management
  - Conflict resolution

Config:
  - Endpoint: firebase_init.js
  - Method: PATCH (update only changed fields)
  - Retry: 3 attempts with exponential backoff
```

## Agent: Google-Cloud-Analyzer
**Type**: Data Processing  
**Scope**: Analytics and reporting  
**Tools**: Google Cloud Vision, BigQuery

```
Features:
  - Process Excel files (GAN.xlsx, invoices.xlsx)
  - Analyze duplicate entries
  - Generate reports
  - Data validation

Requires:
  - GOOGLE_API_KEY (in settings.json) or GOOGLE_APPLICATION_CREDENTIALS
  - GOOGLE_PROJECT_ID
  - Billing account linked to Google Cloud

Notes:
  - If your environment does not use an API key, set a service account JSON path in `GOOGLE_APPLICATION_CREDENTIALS`.
  - This avoids the error: "Failed to get Google credentials: google: could not find default credentials."
```

## Integration Points
- **Input**: Excel files, JSON data, Firebase
- **Output**: HTML reports, JSON exports, validation logs
- **Storage**: Local cache in `scratch/`, Firebase backup

## Error Handling
- Automatic retry on network failures
- Preserve field integrity during updates
- Log all changes to activity.js
